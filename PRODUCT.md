# Карточка

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Python/FastAPI, React/TypeScript. Пользователь разрешил React и попросил хорошую,
чистую архитектуру. Backend и UI разделены; браузер обращается к одному API.

## Users
Контент-менеджер B2B-магазина контрольно-измерительных приборов.

## Product Purpose
Получить из JSON удобный для копирования черновик карточки: SEO-заголовок,
описание 800–1200 символов, параметры, запросы и блок для менеджера.

## Capabilities and Constraints
Параметры берутся только из входа. Пробелы явно отмечаются. Есть реальный LLM API
и отдельный явно обозначенный offline demo. Все результаты требуют проверки.
Нет базы, регистрации, фоновых задач и публикации в магазин.

## Evidence on Hand
В задании есть один неполный пример манометра. Данные второго товара не предоставлены:
пользователь подтвердил это. Второй товар — вымышленная демонстрационная фикстура.
